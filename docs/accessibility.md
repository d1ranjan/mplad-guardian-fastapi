# Accessibility Pass

The primary analyst routes use semantic tables with scoped column headers, descriptive labels for search and dashboard filtering controls, visible focus rings from the shared component system, keyboard-accessible buttons and links, and responsive single-column layouts for case review and import flows. The sidebar uses labelled navigation controls, reviewer actions are buttons that open a labelled dialog, and import inputs are associated with an accessible label.

Final acceptance should include a manual keyboard-only walkthrough after deployment: dashboard quick filter, alert queue search/filter controls, case-review dialog, CSV chooser, and the mobile sidebar trigger.
